# Architecture Overview

## Domains

- Publisher: users, publishers, websites, content.
- Advertising: campaigns, ads, placements.
- Affiliate: networks, accounts, offers, referrals.
- Tracking: clicks, sessions, conversions.
- AI: research, matching, optimization, and content workflows.

## Decision flow

Content -> topic extraction -> eligible offer discovery -> policy filters -> commercial scoring -> placement recommendation -> publication -> click/conversion tracking -> revenue optimization.

AI recommendations never bypass eligibility, disclosure, advertiser, or publisher policy rules.
