# AI Ad & Affiliate Management Platform

AI-assisted publisher monetization platform for content, advertising, affiliate offers, referral attribution, and revenue optimization.

## Sprint 1

- Monorepo foundation
- Admin dashboard shell
- API service foundation
- PostgreSQL/Prisma domain model
- AI/ad/affiliate package boundaries
- Background worker foundation
- Tracking service foundation
- CI-ready repository layout

## Development

Requirements: Node.js 20+, pnpm 9+, PostgreSQL 16+, Redis 7+.

```bash
pnpm install
pnpm dev
```

Copy `.env.example` to `.env` and configure database/Redis credentials before starting services.
